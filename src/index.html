常见问题

评估合同 AI，你需要知道这些

所有能力说明均来自项目架构材料，不包含未经验证的宣传。

契审通解决什么问题？

它把多格式合同转换为版本化数据，让受控 Agent 完成检索、确定性校验与候选生成，再由授权审批决定正式写入。

支持哪些合同文件？

当前架构明确覆盖 PDF、Word 与 Excel，并通过独立解析队列完成格式识别、条款切分和版本持久化。

AI 的答案可以追溯吗？

可以。检索结果、来源引用、工具调用与步骤状态被持久化，审核人员可从候选结论回到对应合同版本和原文证据。

哪些工作不交给大模型？

日期、金额、付款、验收等可确定计算由程序工具执行；模型主要负责语义理解、计划和候选生成。

为什么需要人工审批？

因为模型输出不是合同事实。候选成果只有通过 RBAC 授权审批后，才能成为报告、风险或履约节点等正式记录。

这是多智能体系统吗？

不是。核心采用单主 Agent Harness，由一个 Runtime 维护计划、历史、预算、工具策略和停止条件，以减少额外协作不确定性。
